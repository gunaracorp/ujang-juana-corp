FILE PALING PENTING UNTUK MENU UNGGAH SHP AMDALNET:
04_UPLOAD_SHP_AMDALNET_JUKNIS_V2_5.zip
Isi ZIP hanya satu layer polygon EPSG:4326 dengan file TAPAK_PROYEK.shp/.shx/.dbf/.prj/.cpg.

FIELD SHP: id (integer); PEMRAKARSA, KEGIATAN, TAHUN, PROVINSI, KETERANGAN, LAYER (text 255); LUAS (decimal hektare). LAYER bernilai tepat: Tapak Proyek.

PERHATIAN GEOMETRI: User hanya memberikan satu titik koordinat pusat dan luas referensi 95 m2. Polygon persegi dibuat sebagai estimasi teknis. Ini bukan batas sertifikat, bukan hasil ukur kadastral, dan belum diverifikasi di lapangan. Jangan menyatakan geometri ini sebagai batas tanah sebenarnya tanpa pengukuran/konfirmasi.

KOORDINAT UTAMA: -7.361490, 108.176140 (EPSG:4326).
ALAMAT: Jl. Karikil, Kampung Cibeureum, RT 001/RW 001, Kelurahan Cipari, Kecamatan Mangkubumi, Kota Tasikmalaya, Jawa Barat

LUAS: 95 m2 = 0.0095 ha. Penghitungan area diselaraskan ke WGS84 ellipsoidal area. Dalam QGIS ikuti ekspresi juknis: $area / 10000 (hektare); pastikan measurement ellipsoid proyek WGS84.
